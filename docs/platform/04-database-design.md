# Database design (PostgreSQL 16)

Status: **proposed** (Phase 0). Migrations will live in `apps/api/migrations/` (SQLx).

## 1. Conventions

- Primary keys: `uuid` (UUIDv7, time-ordered) generated by the API.
- Every tenant-scoped table has `workspace_id uuid not null` with a foreign key and an index
  leading with `workspace_id`.
- Timestamps: `timestamptz`, `created_at default now()`.
- Enums as `text` with `check` constraints (easier to migrate than Postgres enums).
- Secrets are never stored in plain text: passwords as Argon2id hashes, tokens as SHA-256 hashes,
  provider keys and Git credentials as AES-256-GCM ciphertext with a key-encryption key from the
  environment or a KMS (`enc_*` columns hold `{key_id, nonce, ciphertext}`).
- **Row-level security** on every tenant table: the API sets `app.workspace_ids` per transaction
  from the authenticated session; policies allow rows only where `workspace_id = any(...)`.
  The application-level membership checks remain the primary control.

## 2. Tables

### Identity and sessions
| Table | Key columns |
|---|---|
| `users` | id, email (citext, unique), display_name, password_hash, mfa_totp_enc, mfa_enabled, status (`active`/`locked`/`deleted`), created_at |
| `devices` | id, user_id → users, kind (`web`/`android`), name, platform_info jsonb, last_seen_at, revoked_at |
| `sessions` | id, user_id, device_id, family_id, refresh_hash (unique), expires_at, rotated_at, revoked_at, revoke_reason, ip_hash, user_agent |
| `login_codes` | code_hash (pk), session_id, expires_at, used_at (single-use WebView exchange) |

### Tenancy
| Table | Key columns |
|---|---|
| `workspaces` | id, name, slug (unique), owner_id → users, plan, quotas jsonb, created_at |
| `workspace_members` | workspace_id, user_id, role (`owner`/`admin`/`maintainer`/`editor`/`viewer`); pk (workspace_id, user_id) |
| `projects` | id, workspace_id, name, kind (`code`/`analysis`/`rebuild`), deep_mode bool, deep_mode_authorization text, default_branch, archived_at |
| `project_members` | project_id, user_id, workspace_id, role; pk (project_id, user_id) |

### Engine and tools
| Table | Key columns |
|---|---|
| `engine_sessions` | id, workspace_id, project_id, worker_id, status (`starting`/`ready`/`stopped`/`failed`), mode (`clean_room`/`deep`), started_at, stopped_at |
| `tool_executions` | id, workspace_id, project_id, engine_session_id, user_id, agent_task_id (nullable), tool, params_redacted jsonb, policy, approval_id, status (`queued`/`running`/`succeeded`/`failed`/`cancelled`/`awaiting_approval`), error_code, evidence_id, duration_ms, created_at |
| `evidence_records` | evidence_id text (`ev_…`), workspace_id, project_id, operation, subject jsonb, confidence, summary, body jsonb (full record), created_at; pk (workspace_id, evidence_id) |
| `approvals` | id, workspace_id, project_id, subject_kind (`tool_call`/`terminal_command`/`git_push`/`deep_mode`/`plan`), subject_id, requested_by, requested_by_agent_task, summary, details jsonb, status (`pending`/`approved`/`rejected`/`expired`), decided_by, decided_at, expires_at |

Evidence bodies are also kept in the workspace volume by the engine (`.cany/evidence/…`); the
table is the searchable index and survives sandbox cleanup.

### Agents and conversations
| Table | Key columns |
|---|---|
| `agents` | id, workspace_id, role, name, model_ref, toolsets text[], system_prompt_ref, enabled |
| `agent_plans` | id, workspace_id, project_id, goal, status (`draft`/`approved`/`running`/`done`/`failed`/`cancelled`), created_by, approved_by |
| `agent_tasks` | id, plan_id, workspace_id, agent_id, title, depends_on uuid[], branch, worktree_path, status, attempt, max_attempts, tokens_in, tokens_out, cost_usd, cost_is_estimate, started_at, finished_at |
| `agent_events` | id bigserial, task_id, workspace_id, seq, kind, payload jsonb, created_at; unique (task_id, seq) |
| `conversations` | id, workspace_id, project_id, user_id, title, backend_ref, created_at |
| `messages` | id, conversation_id, workspace_id, role, content jsonb, tokens, created_at |

### Jobs and events (shared by agents, builds, git, long tool calls)
| Table | Key columns |
|---|---|
| `jobs` | id, workspace_id, kind, ref_id, status, priority, run_after, locked_by, locked_until, attempts, max_attempts, last_error |
| `job_events` | job_id, seq, workspace_id, kind, payload jsonb, created_at; pk (job_id, seq) |

Workers claim jobs with `FOR UPDATE SKIP LOCKED` and renew `locked_until`. An expired lock puts
the job back to `queued` (with `attempts + 1`), which is how a crashed worker is recovered.

### Terminal
| Table | Key columns |
|---|---|
| `terminal_sessions` | id, workspace_id, project_id, user_id, sandbox_id, status, started_at, last_input_at, expires_at, ended_reason |
| `terminal_commands` | id, terminal_session_id, workspace_id, command_redacted, flagged_sensitive bool, approval_id, created_at |

Raw terminal output is not stored by default; it streams only. Command lines are recorded for audit
after secret redaction.

### Git
| Table | Key columns |
|---|---|
| `git_connections` | id, workspace_id, provider (`github`/`gitlab`/`generic`), auth_kind (`token`/`ssh_key`/`oauth`), enc_secret, scopes, created_by, last_verified_at |
| `git_repositories` | id, workspace_id, project_id, connection_id, remote_url, default_branch |
| `git_operations` | id, workspace_id, repository_id, user_id, agent_task_id, op (`clone`/`fetch`/`pull`/`push`/`commit`/`merge`/`branch`/`tag`), ref, status, job_id, approval_id |

### Builds and artifacts

### Providers, usage, audit, notifications

## 3. Indexes (initial)

- `(workspace_id, created_at desc)` on `tool_executions`, `audit_logs`, `builds`, `usage_records`.
- `(project_id, status)` on `agent_plans`, `builds`.
- `jobs (status, priority desc, run_after) where status = 'queued'` (partial index for claiming).
- `sessions (user_id) where revoked_at is null`.
- `notifications (user_id, created_at desc) where read_at is null`.
- GIN on `evidence_records.subject` for search.

## 4. Retention

| Data | Default retention |
|---|---|
| `job_events`, `agent_events` | 30 days after the job finishes |
| `audit_logs` | 1 year, then archived |
| `artifacts` | 30 days unless pinned |
| `sessions` (revoked/expired) | 30 days |
| `usage_records` | 13 months |
| `terminal_commands` | 90 days |

A daily job deletes expired rows in batches. Retention values are per-workspace settings with
these defaults.

## 5. Backup and restore

`pg_dump` nightly plus WAL archiving for point-in-time recovery; artifacts and workspace volumes
backed up separately. A restore test (Phase 9) restores into a scratch database and runs the
migration checksum and row-count checks.
